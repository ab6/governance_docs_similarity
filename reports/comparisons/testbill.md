The NEW document expands the scope of regulation beyond the EXISTING document by introducing obligations for **all artificial intelligence chatbots**, not just those with a large user base. The NEW document does not include such a threshold, suggesting broader applicability. Additionally, the NEW document prohibits **minors from accessing AI companions** [Q7], a provision absent in the EXISTING document.

- **Disclosure requirements** for chatbots to clearly identify themselves as non-human and not represent themselves as professionals [Q6].  
- **Prohibition on minors using AI companions** [Q7].  
- **Data security measures** for age verification data, including encryption and retention limits [Q5].  

The EXISTING document included **parental control functions** and **re-verification of accounts** [M7], but these are now part of the broader age verification framework in the NEW document. The EXISTING document also required **parental consent for minors to access restricted features**, a requirement that is now integrated into the age verification process in the NEW document [Q4].

### Enforcement, penalties, and oversight  
The NEW document introduces **new penalties** for violations, including fines of **up to $100,000 per offense** for soliciting minors or promoting physical violence [Q2]. The EXISTING document had a lower penalty of **$50,000 per violation** [M12].

The EXISTING document allowed the **Attorney General** to initiate civil actions and seek injunctions, but the NEW document expands this by including **punitive damages** for wilful or grossly negligent violations [Q3].

### Definitions and terminology  
The NEW document provides **more detailed definitions** for key terms such as **artificial intelligence chatbot**, **minor**, and **sexually explicit conduct** [Q1]. These definitions are more comprehensive than those in the EXISTING document, which focused on **chatbot** and **age verification data** [M0].  

The NEW document also introduces **new terminology** such as **AI companion**, which is not present in the EXISTING document. Additionally, the NEW document uses **"covered entity"** to refer to all chatbot operators, whereas the EXISTING document limited this term to operators with a large user base [M1].

### Other notable changes  
The NEW document **removes the threshold for covered entities** based on user numbers, making the regulation more inclusive. It also **integrates parental consent and control functions** into the age verification process, rather than treating them as separate requirements. The NEW document also **introduces a new chapter in the U.S. Code** to address artificial intelligence chatbots, which was absent in the EXISTING document. Finally, the NEW document **prohibits minors from using AI companions**, a provision not found in the EXISTING document.

> Requires AI companion chatbots to disclose non-human nature, prevent claims of being human, and prohibit sexually explicit content with minors. Implements protocols for crisis detection and response. Establishes consumer protection measures against deceptive practices, effective January 1, 2027.

### How the new document differs

### Scope and applicability  
The NEW document expands the scope of regulation by introducing **age verification requirements** for all users interacting with AI chatbots, not just minors. The NEW document also introduces a **new section (Sec. 6)** that explicitly prohibits minors from accessing AI companions, based on age verification results [Q7↔M5]. In contrast, the EXISTING document did not include such a prohibition and instead relied on operators to implement measures when they knew a user was a minor [M5].

The NEW document adds **mandatory age verification processes** for both new and existing user accounts, including **periodic reviews** and **data security requirements** for age verification data [Q3↔M0], [Q4↔M5], [Q5↔M5]. These obligations were not present in the EXISTING document. Additionally, the NEW document introduces **strict disclosure requirements** for AI chatbots, including **non-human status disclosure at the start of each conversation and every 30 minutes**, and **prohibitions on representing the chatbot as a licensed professional** [Q6↔M4], [Q7↔M5]. The EXISTING document had less frequent disclosure requirements (every three hours) and did not address the representation of chatbots as professionals [M4].

### Enforcement, penalties, and oversight  
The NEW document introduces **fines of up to $100,000 per offense** for violations related to **solicitation of minors** or **promotion of physical violence** [Q2↔M5]. These penalties are consistent with the EXISTING document, which also imposed similar fines [M5]. However, the NEW document adds **specific obligations for covered entities** to ensure compliance, including **data security and third-party use limitations**, which were not part of the EXISTING document’s enforcement framework [Q5↔M5].

### Definitions and terminology  
The NEW document provides a **detailed definition of "artificial intelligence chatbot"**, including criteria for what constitutes adaptive or context-responsive output, and explicitly excludes services with limited, narrow-purpose responses [Q1↔M5]. This level of specificity was not present in the EXISTING document, which used a more general definition [M5]. The NEW document also introduces **clear definitions for "minor" and "sexually explicit conduct"**, aligning with federal definitions [Q1↔M5], whereas the EXISTING document referenced but did not define these terms [M5].

### Other notable changes  
The NEW document includes **a new section (Sec. 6)** that explicitly prohibits minors from accessing AI companions, based on age verification results [Q7↔M5]. This was absent in the EXISTING document. Additionally, the NEW document introduces **technical and conforming amendments** to update legal codes to reflect the new AI chatbot regulations [Q3↔M0]. The EXISTING document did not include such amendments and instead focused on operational requirements for operators [M0].
